# Konzilo

Konzilo is a core for websites whose editors write Markdown and whose visitors get a static site built by Astro.

## Status

**Under construction.** The content format, the Astro integration, editing in Sveltia CMS with a Crepe body field, publishing through an intake, and running everything with Docker Compose exist. [`CHANGELOG.md`](CHANGELOG.md) says what each release holds.

## Acknowledgements

Konzilo is built on Astro, Sveltia CMS, Milkdown and Sätteri, runs beside Forgejo and Caddy, and uses many libraries. [`ACKNOWLEDGEMENTS.md`](ACKNOWLEDGEMENTS.md) names them, with thanks, and says how their licenses fit. [`THIRD-PARTY.md`](THIRD-PARTY.md) lists every package the core installs.
