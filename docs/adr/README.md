# Architecture decisions

This index lists every architecture decision record (ADR) of Konzilo. An ADR is a file named `NNNN-short-title.md` in this directory.

Add each ADR as one line, in number order: `- [ADR NNNN: Title](NNNN-short-title.md) — what it decides`.

Each ADR gives the date, the status, the decision and why, the alternatives that were rejected where the rejection is not obvious, and what practice has shown. A status says whether Thomas settled it, in his words where they exist, or whether it is a technical choice he may veto. None of his settled decisions is changed without his yes.

Read an ADR before reversing or questioning its decision. A new decision that changes an old one amends it in the same change.
